# گالری هنر - چندزبانه (Multi-Language)

## زبان‌های پشتیبانی شده

- 🇮🇷 **فارسی** (پیش‌فرض) - `/fa`
- 🇬🇧 **English** - `/en`
- 🇪🇸 **Español** - `/es`

## ویژگی‌های چندزبانه

✅ تمام متن‌های UI به سه زبان  
✅ تغییر زبان از طریق منوی ناوبری  
✅ پشتیبانی RTL برای فارسی  
✅ URL-based routing برای هر زبان  
✅ SEO-friendly برای هر زبان  

## نحوه استفاده

### تغییر زبان

1. روی آیکون **Globe** در نوار ناوبری کلیک کنید
2. زبان مورد نظر را انتخاب کنید
3. صفحه به زبان انتخابی تغییر می‌کند

### URL های مستقیم

- فارسی: `http://localhost:3000/fa`
- انگلیسی: `http://localhost:3000/en`
- اسپانیایی: `http://localhost:3000/es`

## ساختار فایل‌های ترجمه

```
messages/
├── fa.json  # فارسی
├── en.json  # انگلیسی
└── es.json  # اسپانیایی
```

## افزودن ترجمه جدید

برای افزودن متن جدید:

1. به فایل‌های JSON در پوشه `messages/` بروید
2. کلید جدید را به هر سه فایل اضافه کنید
3. ترجمه را در هر زبان بنویسید

مثال:
```json
{
  "newSection": {
    "title": "عنوان جدید",
    "description": "توضیحات"
  }
}
```

## استفاده در کامپوننت‌ها

```tsx
'use client';

import { useTranslations } from 'next-intl';

export function MyComponent() {
  const t = useTranslations('sectionName');
  
  return <h1>{t('title')}</h1>;
}
```

## نکات مهم

- زبان پیش‌فرض: فارسی (`fa`)
- RTL به صورت خودکار برای فارسی فعال می‌شود
- تمام لینک‌ها باید شامل locale باشند
- از `useLocale()` برای دریافت locale فعلی استفاده کنید
