# Setup Guide

This guide will walk you through setting up the Cyberpunk Photo Gallery application.

## Prerequisites

- Node.js 18+ installed
- npm, yarn, or pnpm package manager
- A Supabase account (free tier is sufficient)
- A Cloudinary account (free tier is sufficient)

## Step 1: Install Dependencies

```bash
cd photo-gallery-app
npm install
```

## Step 2: Set Up Supabase

1. **Create a Supabase Project**
   - Go to [supabase.com](https://supabase.com)
   - Create a new project (free tier works)
   - Wait for the project to initialize

2. **Get Your Supabase Credentials**
   - Go to Project Settings > API
   - Copy your Project URL and anon/public key
   - Go to Project Settings > API > Service Role Key
   - Copy your service role key (keep this secret!)

3. **Set Up the Database**
   - Go to the SQL Editor in your Supabase dashboard
   - Copy the contents of `supabase-setup.sql`
   - Run the SQL script to create the photos table and policies

4. **Set Up Authentication (Optional for Admin)**
   - Go to Authentication > Users in Supabase
   - Create a new user for admin access
   - Or use the email/password auth provider

## Step 3: Set Up Cloudinary

1. **Create a Cloudinary Account**
   - Go to [cloudinary.com](https://cloudinary.com)
   - Sign up for a free account

2. **Get Your Cloudinary Credentials**
   - Go to Dashboard
   - Copy your Cloud Name, API Key, and API Secret

3. **Enable Auto-Tagging (Optional but Recommended)**
   - Go to Settings > Upload
   - Enable "Auto Tagging" with Google Vision API
   - This will enable AI-powered search features

## Step 4: Configure Environment Variables

1. **Copy the example file**
   ```bash
   cp .env.local.example .env.local
   ```

2. **Fill in your credentials** in `.env.local`:
   ```env
   # Supabase Configuration
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key_here
   SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here

   # Cloudinary Configuration
   NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=your_cloud_name
   CLOUDINARY_API_KEY=your_api_key
   CLOUDINARY_API_SECRET=your_api_secret
   ```

**Important**: Never commit `.env.local` to version control!

## Step 5: Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see your gallery!

## Step 6: Create an Admin Account

1. Go to [http://localhost:3000/auth/login](http://localhost:3000/auth/login)
2. If you haven't created a user yet:
   - Go to your Supabase dashboard
   - Navigate to Authentication > Users
   - Click "Add user" and create an admin account
   - Or use Supabase Auth to sign up

3. Log in with your admin credentials
4. You'll be redirected to the Admin Dashboard where you can upload photos

## Features Overview

### Home Page
- **Hero Section**: Animated vortex effect with featured photos
- **Gallery**: Masonry layout with search and filter
- **Lightbox**: Full-screen image viewing with zoom and share

### Admin Dashboard (`/admin`)
- **Upload Zone**: Drag-and-drop image upload
- **Batch Upload**: Upload multiple images at once
- **Metadata**: Add title, description, and category to images

### Search & Filter
- **AI Search**: Search by tags automatically generated by Cloudinary
- **Category Filter**: Filter by Portrait, Landscape, Abstract, or Nature
- **Real-time**: Instant results as you type

## Troubleshooting

### Images Not Loading
- Check your Cloudinary credentials in `.env.local`
- Verify images are uploaded correctly
- Check browser console for errors

### Authentication Issues
- Verify your Supabase URL and keys are correct
- Check that RLS policies are set up correctly
- Make sure your user exists in Supabase

### Upload Fails
- Check Cloudinary API credentials
- Verify file size limits (default: 10MB)
- Check browser console for specific errors

### Database Errors
- Run the SQL setup script again
- Check that all indexes are created
- Verify RLS policies are enabled

## Production Deployment

### Vercel (Recommended)

1. Push your code to GitHub
2. Import your repository in Vercel
3. Add all environment variables in Vercel dashboard
4. Deploy!

### Environment Variables for Production

Make sure to set all environment variables in your hosting platform:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (server-side only)
- `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`
